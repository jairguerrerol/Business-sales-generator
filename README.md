# Business sales generator

Automated report generation system developed with Python and Pandas for small businesses.
This project processes sales data, calculates key business metrics, and automatically generates Excel reports that support decision-making.

Features:
Read sales data from CSV files
Calculate total revenue
Compute average revenue
Generate business summaries
Export reports to Excel
Create separate worksheets for raw data and executive summaries
Automate repetitive reporting tasks

Technologies Used:
Python
Pandas
OpenPyXL
Excel
